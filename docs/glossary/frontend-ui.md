# Glossary · 客户端 UI 术语

> 人 ⇄ Agent 对齐用；工程事实仍以 `CONTEXT.md` 为准。

| 词 | 含义 | 代码锚点（约） |
|---|---|---|
| 侧栏页面 | 左侧导航注册的功能页 | `CLIENT/apix-app/src/renderer/src/router/pageRegistry.js` |
| 消息树 | 可分支的对话消息结构 | Memory 消息节点 + 渲染进程消费 |
| 任务流编辑器 | 卡片化 / 可视化编排 UI | 客户端视图 + Task 服务 |
| 设置页 | Provider / MCP / 用户配置 | `showcase-settings` 对应界面 |
| 工作区页 | 文件 / 源码浏览相关界面 | `showcase-workspace` |
| 主对话页 | 聊天与 Agent 协作主界面 | `showcase-main` |
| 编辑器页 | 代码/文档编辑相关界面 | `showcase-editor` |
